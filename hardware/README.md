# Hardware documentation

Record the physical details needed to reproduce and safely operate each
component here. Each component document should include:

- Board model and a way to identify the physical board
- Pin-to-signal wiring table
- Supply voltage, grounding, and driver circuitry
- Active-high or active-low behavior
- Safe GPIO state during boot and reset
- Mechanical limits, sensors, and operation timeouts
- A photo or diagram when it makes the wiring clearer

Do not place credentials or other secrets in hardware notes.
